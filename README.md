# AI Grade Predictor

A machine learning pipeline built to predict student academic outcomes based on study habits and social media usage. 

## Overview
This project demonstrates end-to-end applied machine learning workflows, from data ingestion and cleaning to model evaluation, utilizing a dataset from Kaggle.

## Key Features
* **Data Preprocessing:** Handled missing values, outliers, and categorical encoding using Pandas.
* **Exploratory Data Analysis (EDA):** Feature correlation visualization using Matplotlib and Seaborn.
* **Model Training & Evaluation:** Regression modeling evaluated via Root Mean Square Error (RMSE) using scikit-learn.

## Tech Stack
* Python
* scikit-learn
* Pandas & NumPy
* Matplotlib & Seaborn
